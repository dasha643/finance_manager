1. **назву проєкту**
   менеджер особистих фінансів

2. **призначення програми**
    менеджер особистих фінансів — це консольна програма, вона дозволяє користувачам керувати своїми доходами та витратами, дивитися поточний баланс і аналізувати фінансові дані за допомогою сортування та фільтрації

3. **основні можливості**
   - створення нових транзакцій
   - перегляд повного списку всіх збережених транзакцій
   - автоматичний розрахунок загальної суми доходів, витрат та поточного балансу
   - фільтрація транзакцій за обраними категоріями

4. **структуру файлів**
   проєкт складається з таких модулів:
   - `main.py` — головний файл програми, який дозволяє взаємодію з користувачем через консольне меню
   - `transactions.py` — модуль для управління транзакціями
   - `statistics.py` — модуль для виконання математичних розрахунків
   - `.gitignore` — файл конфігурації для виключення системних файлів середовища розробки з системи контролю версій

5. **інструкцію запуску**
   - потрібен встановлений Python на комп'ютері
   - завантажте репозиторій із проєктом
   - відкрийте термінал у кореневій папці проєкту (`finance_manager`)
   - запустіть програму за допомогою команди:
      ```bash
      python main.py
      ```

6. **приклади використання**
   - **додавання транзакції:** після запуску програми оберіть пункт створення транзакції, введіть тип (`income` для доходу або `expense` для витрати), суму (наприклад, `500`), категорію (`Food` або `Salary`) та опис
   - **перегляд балансу:** оберіть у меню відповідний пункт, щоб побачити загальний баланс, суму всіх доходів і витрат за введеними даними
   - **фільтрація:** оберіть пункт фільтрації за категорією та введіть назву категорії, щоб переглянути пов'язані з нею операції
